# Security

This source snapshot is intended for review and controlled, owner-authorized deployments.

It is remote administration software: give the Windows agent a low-privilege account, strong OS ACLs, limited filesystem roots, explicit command allowlists, and a protected HTTPS/WSS endpoint.

Do not disable antivirus or create exclusions solely to run this project. Investigate any endpoint security detection independently before deploying.

No prebuilt Windows executables or production configuration are distributed here. Source availability does not certify the code or the build chain as safe.

Please report suspected security vulnerabilities privately to the repository owner instead of publishing credentials or exploit details in public issues.
